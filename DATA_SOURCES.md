# Data Sources

The organizer-provided S001–S010 synthetic cases are preserved verbatim in `data/seeds/synthetic-patients.json`. They are input seeds, not labeled clinical ground truth. ClinicalTrials.gov API v2 records and project-generated benchmark data will be documented with capture timestamps, hashes, terms, and non-endorsement language when added in their specification phases. TREC 2022 retrieval is not yet run.
